Sceller une signature

Chiffre le fac-similé de signature avant de le confier à MATRICE.

Étape 1 sur 3
Un PNG à fond transparent — la signature détourée, ou le cachet. Le fichier est lu par cette page seule ; il n'est envoyé nulle part.
Étape 2 sur 3
Cette phrase sera demandée à chaque envoi signé. Elle n'est stockée nulle part : ni ici, ni dans MATRICE, ni chez Vercel. Perdue, elle ne se retrouve pas — il faudrait sceller l'image à nouveau.
Étape 3 sur 3
Colle-le dans Vercel → matrice → Settings → Environment Variables, sous le nom MATRICE_SIGNATURE_SCELLEE (ou MATRICE_CACHET_SCELLE pour le cachet), en Production et Preview. Cette variable peut rester en clair dans la configuration : sans ta phrase, elle ne vaut rien.
Pourquoi cette page est un fichier local. Le chiffrement se fait ici, dans ton navigateur, par les fonctions cryptographiques du système. Ton image en clair et ta phrase secrète ne quittent jamais ce poste — aucune requête réseau n'est émise, tu peux le vérifier en coupant le wifi avant de cliquer.

PBKDF2-SHA256, 600 000 itérations, puis AES-256-GCM. Le sceau d'authentification fait qu'une phrase fausse ne rend pas une image approximative : elle ne rend rien du tout.
